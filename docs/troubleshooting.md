# 常见问题

适用于本仓库的 captions / cloud 稳定版。先确认当前会话的工作区，再到 **DSH 设置 → 视频学习** 检查相应设置。不要用反复重试来代替检查上传目标与计费状态。

## 安装与环境

| 现象 / 状态 | 常见原因 | 下一步 |
| --- | --- | --- |
| 没有“视频学习”设置或工具 | 插件未安装/启用，或 DSH 版本不匹配 | 按[首页](../README.md)安装与启用；不要把开发源码目录当成已安装插件。当前稳定版不包含本地 ASR。 |
| `dependency_missing`、找不到 Python | 未准备运行环境，或选中了错误解释器 | 先保存设置，再点“一键准备运行环境”。需 Python 3.10+；它在设置的状态目录（默认用户目录下 `.dsh/state/dsh-video-study`）创建隔离环境，不修改系统 Python，也不是把依赖安装进插件源码目录。失败时根据界面静态提示处理，不需要下载识别模型。 |
| 选择 Python 后仍使用旧路径 | 文件夹选择只更新草稿 | 选择安装/venv文件夹后点“保存设置”，再“检查环境”；也可恢复默认 Python 后保存。不要把文件夹路径直接当成解释器文件路径手工填写。 |
| “检查环境”成功，但提取/转写失败 | 检查仅离线完成，不测试平台、凭据、余额或识别服务 | 阅读实际提取状态；`status: ok` 不是所有依赖或真实服务可用的保证。准备依赖也不会验证服务商账号。 |
| 按钮灰色，提示有未保存修改 | 设置仍是草稿 | 先保存；若提示并发冲突，重新载入并重做需要的修改。重新载入可能丢弃未保存草稿。 |
| `workspace_required` | 任务没有当前会话工作区，且未显式设置绝对输出目录 | 在有工作区的会话中执行，或设置对应的绝对目录。默认目录随当前工作区变化，不随系统命令行目录猜测。 |
| `workspace_unavailable` / `directory_invalid` | 目录不可写、含符号链接/联接、UNC或设备路径等 | 选择可写的本机普通绝对目录，检查父目录权限；不要靠切换到系统临时目录绕过错误。插件不会悄悄改写到其他位置。 |

默认原始材料在工作区的 `video-study/transcripts`，最终文档在 `video-study/documents`；设置中的输出目录可覆盖相应默认值。文件名含唯一标识，已有文件不覆盖；若遇到 `output_exists`，换一个新输出路径，不必删除已有结果。

## 字幕、登录和语言

| 现象 / 状态 | 常见原因 | 下一步 |
| --- | --- | --- |
| B站提示未登录、登录过期、二维码失效 | 平台要求登录，或已有登录态不可用 | 在视频学习的 B站登录区重新扫码并在 App 确认，或按界面导入自己的 Cookie 文件；不要把 Cookie 粘贴到聊天。不要同时配置冲突的文件与托管登录态。 |
| `no_captions` | 当前视频/分P没有可用已有字幕 | 核对链接和分P；仅字幕模式到此停止。确需识别时，另行配置并授权[云端服务](cloud-services.md)。 |
| `language_unavailable` | 没有符合本次源语言的字幕；自动翻译轨不算源字幕 | 核对源语言和所选轨道；仅在确实希望改变要求时改语言，不要把自动翻译当原文。云端模式可在此状态接续识别。 |
| `network_error` / `caption_error` / 权限错误 | 请求未完成、网络/平台限制，并不证明无字幕 | 先解决平台可访问性、登录和代理问题；这种错误不会自动下载音轨做 ASR。 |
| 已配置云端，但仍获取到平台字幕 | 已有字幕优先，是正常行为 | 若字幕内容确实错误或不可靠，本次明确提出重识别；不要只因“云端模式”就期待上传。`captionsOnly` 始终禁止 ASR。 |
| 文件成功生成，但内容不是该讲/分P或缺段 | 平台字幕、语言选择或识别结果仍需校对 | 核对标题、链接分P、开头结尾和全文覆盖；成功状态与警告都不是内容正确性认证。 |

每次提取都需要重新选择“原文（完全复述）/ 简要压缩 / 总结”，不沿用上次。简要或总结只改变最终课程正文，原始字幕/ASR材料仍完整保留。

## 云端上传与服务错误

先按[云端配置指南](cloud-services.md)核对**协议 + 完整接口地址 + 模型 + 对应凭据**。服务名称只是备注。

| 现象 / 状态 | 原因 / 下一步 |
| --- | --- |
| `upload_consent_required` | 勾选“允许上传音频到此服务（可能产生费用）”并保存。改地址、协议、应用/凭据标识、地域或资源ID后需再次确认；别忘了检查仍保留的旧 Key。 |
| Key 输入框始终空白 | 不回显保存的秘密是正常行为；留空保留已有 Key，清除需勾选相应复选框再保存。 |
| `invalid_api_key` / `credential_file_invalid` | Key不能有空格、换行或非ASCII字符，不会自动截断。Key文件须为可读的绝对路径、UTF-8纯文本；已保存 Key 优先。不要提交凭据正文求助。 |
| `invalid_endpoint` / `insecure_endpoint` | 填完整 API 接口而非控制台网址；远程用 HTTPS，去掉地址中的凭据、查询参数和片段。回环HTTP例外只适用于明确允许的本机兼容服务。 |
| `protocol_model_mismatch` | filetrans 异步模型不能用聊天或 OpenAI兼容文件协议。选择“DashScope Paraformer异步”及 `/api/v1/services/audio/asr/transcription`。 |
| `authentication_failed` / `access_denied` | 到服务商控制台核对 Key所属地域、产品开通、模型/资源权限及额度；插件不会换 Key 或换服务重试。 |
| `invalid_proxy` / `unsupported_proxy` / `proxy_loopback_conflict` | 云端仅支持显式无认证的 `http://host:port` 代理，不能带路径/查询；本机明文回环接口不能同时配代理。不要靠关闭 TLS 验证解决。 |
| `rate_limited` / `timeout` | 查服务商任务/费用状态，必要时等待再手动重试或调整合理时限。不会自动重传；客户端超时不证明云端任务已经取消。 |
| `size_limit` / `audio_too_large` / `request_too_large` | 同时受本次MiB限制及服务商上限约束：Qwen聊天编码后10,000,000字节；腾讯内联原音频5,000,000字节；火山100,000,000字节且2小时。提高设置不能绕过这些限制，不会自动分块或截断。 |
| 火山转换时 `dependency_missing` | 部分容器需 PATH 中已有的 ffmpeg；准备 Python 环境不会安装它。直接支持 wav/mp3/ogg/opus，其他已支持格式转换后还要再检查大小。 |
| `redirect_rejected` / `unsafe_provider_url` | 服务返回了重定向或不符合安全约束的上传/结果地址；插件停止而不转发凭据。核对官方域名和地域，不应通过放宽白名单或公开音频来绕过。 |
| `task_failed` / `provider_error` | 服务未完成或拒绝任务。核对账户与音频要求，并查看安全的阶段信息；不要把原始响应或带签名的结果URL发到公开问题区。 |
| `invalid_response` / `unsupported_timestamp` / `invalid_timestamps` | 返回格式、正文或真实时间戳不符合协议。核对模型与接口；OpenAI兼容服务可按文档改“响应请求格式”，不是随意给文本伪造分段时间。 |
| `language_mismatch` | 返回语言不符合本次要求；检查源音轨与语言。自动检测也可能识别错误，不能替代校对。 |

### 只有全文，没有 SRT，是失败吗？

不一定。Qwen聊天及部分兼容服务只提供纯文本：保留原始结果和 TXT/Markdown，明确提示没有时间戳，因此不生成 SRT。**不会按字数均分、猜时间或伪造字幕。**如果必须有字幕时间轴，请选择确实返回真实分段的协议与模型。

## Word与最终课程文档

- Word导出需要 python-docx；缺少时先准备运行环境，Markdown/TXT导出不需要该依赖。
- 导出只负责将**已整理的课程正文**写成一个最终文件，不会在导出时另行提取视频、调用ASR或自动总结。
- 支持有限 LaTeX 转原生 Word 公式。出现 `formula_unsupported` 时，原公式会原样保留并显式警告，不是悄悄删掉或改成“验证通过”。检查相应公式；必要时使用更简单的受支持写法，不能为了消除警告改动数学含义。
- 若只看到原始转写材料，先让助手通读、整理与核对全文，再导出最终课程正文；原始材料不是已校订讲义。

## 提问或报错时提供什么

提供：插件/DSH版本、模式和协议、复现步骤、静态状态码、可选的 `stage`，以及不含秘密的现象描述。说明是离线测试、环境检查还是已授权的真实调用。

**不要提供** API Key、Access Token、SecretKey、Cookie/SESSDATA、上传凭证、完整任务响应、签名链接或私密音频。截图先遮住这些字段以及个人目录/课程隐私。离线 fixture 通过不等于所有厂商、账户和地区都已实测。
