# 高级设置与使用边界

## 三种目录不要混淆

| 用途 | 留空时的位置 | 设置项 |
|---|---|---|
| 最终 Word / Markdown / TXT | 当前会话工作区下 `video-study/documents` | 文档输出目录 |
| 原始字幕、ASR 与元数据 | 当前会话工作区下 `video-study/transcripts` | 原始资料输出目录 |
| Python 配套环境 | Windows：`%USERPROFILE%\.dsh\state\dsh-video-study`；其它平台：`~/.dsh/state/dsh-video-study` | 状态目录 |

前两项是任务产物，随会话工作区变化。第三项是插件托管的运行环境，与工作区无关，因此设置页没有打开会话也能准备环境。

目录可以显式设为本机绝对路径，分别覆盖对应默认值。没有会话工作区且未指定相应输出目录时，任务停止，不回退系统临时目录或用户文档目录。写工作区外的显式路径仍受宿主文件权限控制。

## Python 与环境准备

- 一键准备创建独立 `venv`，安装 `yt-dlp==2026.8.19`（YouTube）和 `python-docx==1.2.0`（Word）。插件本身不安装 Python，也不提供本机语音识别模型。
- 在 Python 路径栏填写解释器文件，或用选择文件夹按钮定位 Python / venv；选择只填入草稿，仍需保存。
- 真正的自定义解释器优先。一键准备不会修改它，应由你在该环境中安装依赖；已经自动填入当前托管 venv 的路径则允许原样重试。
- 状态目录下若已有非本插件创建、但确认为真实 venv 的同名目录，准备操作会给旧目录加唯一后缀保留，不删除；普通目录、链接或不安全路径仍拒绝修改。
- 「生成部署命令」只生成文本，不会执行。需要离线部署或特殊网络设置时，先检查命令，再由你手动运行。

离线检查不会连接 ASR、验证 Key 或判断账号余额。它通过只表示被检查的配置与依赖可用，并不是一次真实课程转写的验收。

## 云端音轨、时间与格式限制

- 上传上限默认 **25 MiB**，可调至 **512 MiB**；服务商限制更小则以较小者为准。火山协议最多 **100,000,000 字节**，腾讯内联录音最多 **5,000,000 字节**。
- 默认课程时长上限 **4 小时**、音轨下载超时 **300 秒**、ASR 总预算 **3600 秒**；可在高级设置中调整。调大本机限制不会改变服务商的限制或额度。
- 超限后停止，不自动切片、不换模型、不切换服务商重试。异步任务取消或超时后，远端可能继续运行和计费；本机停止等待不等于远端撤销。
- 返回正文但没有真实时间戳的服务可以保存正文，不会按字数均分时间，不会编造 SRT/VTT。
- 火山接口遇到不支持的音频容器时，需要系统 `PATH` 中已有的 ffmpeg 做本地转换；本稳定线不下载或安装 ffmpeg。只有真正需要转换时才检查，缺少它不会阻断纯字幕任务。

## 文档导出

在 **文档输出** 中保存格式与目录。默认 `.docx`；选择 `.md` / `.txt` 时不需要 Word 依赖。

助手先完整读取素材、按本次已选详略整理正文，再离线导出。导出工具不会替助手完成翻译、总结或理论核验，不读取 ASR 密钥，也不下载正文里的外部资源。

Word 会把支持的 LaTeX 转成可编辑公式；不支持的语法保留原文并警告。转换成功不代表公式正确。标题最多 200 字符，导出请求最多 2 MiB；生成新文件名，不覆盖旧稿。

## B站登录与代理

在 **B站登录** 标签扫码，并在手机上确认；也可显式选择 Cookie 文件导入。不读取浏览器 Cookie 或密码，不绕过登录、付费或风控限制。

会话由宿主凭据服务保存；Windows 使用同一用户可解密的 DPAPI，其它平台无法安全持久化时只保存在内存。退出只删除本插件记录，不注销其它设备；已退出后不回退旧 Cookie 文件。

字幕和音轨可使用设置里的显式、无凭据 HTTP 代理。扫码及登录检查不支持代理。不要将含用户名/密码的代理 URL、Cookie、二维码或凭据备份放进 Issue。

## 临时文件与凭据

每次任务的 Python、音轨和必要的字幕 Cookie 临时副本绑定本次任务目录；正常结束只清理本次独占内容，不更改全局 `TMP` / `TEMP`。进程树终止无法确认时保留并提示，强制杀进程也可能留下临时音轨，不会扫描删除你的其它文件。

API Key 保存于宿主配置或显式指定的密钥文件。输入框遮掩不等于加密；更换 URL、协议或相关身份标识会撤销上传授权，但保留 Key。重新勾选授权前请确认目标服务。

更完整的数据流与问题报告要求见[安全说明](../SECURITY.md)。
