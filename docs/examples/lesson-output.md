# 同一段内容，三种整理方式

## 用于说明的原始内容

“我们来解一元一次方程 ax+b=0。先考虑 a 不等于零，把 b 移到右边得到 ax=-b，两边再除以 a，所以 x=-b/a。比如 2x+6=0，移项得 2x=-6，因此 x=-3。这里一定要注意 a 不等于零；a 等于零时，b 也等于零就任意 x 都成立，b 不等于零就没有解。”

## 1. 原文（完全复述）

### 一元一次方程的求解

考虑方程 $ax+b=0$。先假设 $a\ne0$，移项得

$$ax=-b.$$

两边除以 $a$，得到

$$x=-\frac{b}{a}.$$

例如，$2x+6=0$，移项得 $2x=-6$，所以 $x=-3$。

这里不能忽略 $a\ne0$ 的条件。当 $a=0$ 时，若 $b=0$，则任意 $x$ 都满足方程；若 $b\ne0$，则方程无解。

**特点：** 按素材顺序保留推导、例子和条件，不因为篇幅短就删除例子。真实课程的“完全复述”基于可获得素材，不意味着已经逐帧核对板书。

## 2. 简要压缩

### 一元一次方程

对 $ax+b=0$，当 $a\ne0$ 时，移项并除以 $a$，解为 $x=-b/a$。

- 例：$2x+6=0\Rightarrow x=-3$。
- $a=0$ 时另行讨论：$b=0$ 则任意 $x$ 均可；$b\ne0$ 则无解。

**特点：** 压缩重复表达，保留核心公式、关键条件和代表例子。

## 3. 总结

### 一元一次方程 · 总结

- $a\ne0$：$ax+b=0$ 的解为 $x=-b/a$。
- $a=0$：由 $b$ 决定恒成立或无解，不能直接除以 $a$。

**特点：** 只保留复习要点，明确标成总结，不冒充完整讲义。
